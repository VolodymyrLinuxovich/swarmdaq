\section{Problem Statement}

Let \(M\) denote a user mission, such as producing a launch plan, market analysis, landing page, risk review, and pitch script for an AI product. A planner maps the mission into a task set
\[
T = \{t_1,t_2,\ldots,t_m\}.
\]
Let \(A = \{a_1,a_2,\ldots,a_n\}\) be the set of candidate agents. Each agent \(a_i\) has skills, historical performance, cost, latency, uncertainty, reputation, and collaboration evidence stored in history \(H\). The system must choose a selected swarm \(S \subseteq A\) and an assignment policy \(\pi:T \rightarrow S\), where \(\pi(t)\) is the agent chosen for task \(t\).

For each agent-task pair \((i,t)\), define an expected quality estimate \(q_{i,t}\), cost \(c_i\), latency \(l_i\), uncertainty \(u_i\), reputation \(r_i\), graph-trust score \(g_i\), and bid utility \(b_{i,t}\). The technical goal is to maximize expected mission quality while minimizing cost, latency, uncertainty, and hallucination risk:
\begin{equation}
\max_{S,\pi}
\left[
\sum_{t \in T} q_{\pi(t),t}
+ \lambda_{\mathrm{syn}}\mathrm{Syn}(S)
- \lambda_c \sum_{a_i \in S} c_i
- \lambda_l \sum_{t \in T} l_{\pi(t)}
- \lambda_u \sum_{a_i \in S} u_i
- \lambda_h \mathrm{HallucinationRisk}(S,M,H)
\right].
\end{equation}
The optimization is constrained by task coverage:
\begin{equation}
\forall t \in T,\quad \mathrm{skills}(\pi(t)) \cap \mathrm{requiredSkills}(t) \neq \emptyset,
\end{equation}
and by the practical requirement that the decision must be explainable to the user. It is not enough to return a final answer; a user should be able to inspect which agents bid, which agent won, which signals influenced the routing decision, how the output was evaluated, and how the result changed future reputation.

\systemname{} therefore treats agent orchestration as a repeated decision process. At run \(k\), routing uses \(H_k\). After execution and evaluation, the system writes \(H_{k+1}\). A good orchestrator should not simply select the historically highest-reputation agent forever. It must also explore under-tested agents, identify useful collaborations, penalize over-rotation, and recover when a previously helpful signal becomes harmful for a different task.
